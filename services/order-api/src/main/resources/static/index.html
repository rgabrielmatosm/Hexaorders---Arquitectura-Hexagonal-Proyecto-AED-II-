Order Management & Risk Assessment System

Pedidos evaluados con arquitectura hexagonal.

Cada pedido entra por un adaptador REST en Java 21, consulta el motor de riesgo en Python a través de un puerto, aplica las reglas del dominio y se guarda en PostgreSQL. Prometheus y Grafana observan el sistema completo.
